# DINNOM

🧭 User Flow

This section outlines the typical user journey through our fashion website:

🏠 1. Landing Page
    Visual-first cover (image/video)
    Scroll reveals:
    ✨ 4x Moodboard Grid Section (interactive visuals)
    🎥 Stories Section (short-form video reels)
    🧍 Shop by Category (Men / Women / Kids)
    🌙 Theme Toggle (Light / Dark)
👤 2. User Authentication
    Click Login / Signup
    Beautiful form UI with animated particles and card tilt effect
    Choose: Email or Social Auth
    Redirect to homepage with personalized view
🛒 3. Product Browsing & Discovery
    Hover-based Sidebar Navigation:
    Tabs for Men / Women / Kids
    Sub-categories like Shirts, Bottoms, Accessories
    Product Grid View with bounce-card hover animations
    Click → View full Product Details:
    Images, Price, Size, Description
    Add to Cart / Wishlist
🎯 4. Outfit Generator (Smart Feature)
    Select Mood (e.g. Minimal / Bold / Chill / Party)
    Apply Budget Filter
    Click “Generate Look”
    AI generates curated outfit within budget
    Option to add full outfit to cart
❤️ 5. Wishlist & Cart
    Users can add/remove items to wishlist
    Cart preview + full page view
    Checkout button enabled when cart has items
💳 6. Checkout Process
    Fill Shipping Details
    Choose Payment Method
    Confirm Order
    Get Order Confirmation (with transaction ID)
📦 7. Order Tracking
    View past orders
    Status updates: Processing → Packed → Delivered
